# ui 模块规范

## 页面与组件

- 使用 MeowUI 公共组件；Material 与 Miuix 的视觉分支留在库内，不复制两套业务页面。
- 先复用 `component` 下的行和分组封装。分组内容通过 scope 的条目 API 声明，不能在条目渲染期间再次注册条目。
- 动态条目使用稳定 key，显隐按现有 `visible` 契约处理；同一行只保留一个点击入口。
- 图标提供必要的无障碍说明；尺寸、配色和排版优先使用主题参数。

## 导航与大屏

- 路由及返回栈由应用统一持有，避免同一页面对象重复入栈；Tab 状态与详情栈分开管理。
- 大屏、折叠屏和分屏布局按可用窗口尺寸适配，优先接 MeowUI 的布局和导航 API。
- 设备专属功能入口使用 `shared` 的设备判断，不以窗口宽度替代设备类型。
- 调整布局时检查首次显示、返回、窗口变窄和 Tab 切换；避免重复组合导致状态丢失或多个返回处理器争用。
- 根页面使用 Shell 提供的内边距，不重复建立 Scaffold 或消费同一份滚动、窗口 inset。

## 状态与设置

- 设置使用 `shared/Preferences` 的同一键、类型、默认值和单位；复用键绑定组件，不在附加回调中重复写入。
- 用户未提交的输入与已保存值分开；连续操作遵循现有提交时机，失败必须反馈。
- 外观状态由统一控制器提供，界面风格、模糊和导航样式均需绑定实际设置。
- 框架操作经 `FrameworkBridge` 调用；`null` 表示尚未读取的状态不能当作空集合或成功结果。
- 包列表、图标和日志读取放到后台；缓存键包含影响结果的输入，页面退出时释放监听。

## 文本与验证

- 用户可见文本放在资源中，新增或修改时同步默认英文和 `values-zh-rCN`；包名、功能 ID 等标识不翻译。
- 应用语言选项与 `app` 的 locale 配置一致；功能说明不混入调试信息、宿主类名和实现步骤。
- 静态检查覆盖偏好接线、枚举分支、资源引用和导航可达性。
- 获准构建时编译 `ui` 或构建应用；获准实机验证时按改动检查两种风格及相关窗口形态，未测项明确记录。
