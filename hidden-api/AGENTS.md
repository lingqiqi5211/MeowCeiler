# hidden-api 模块规范

## 用途与边界

- 此模块只为编译提供平台隐藏类的签名，运行时使用设备上的真实实现。
- 调用侧使用 `compileOnly` / `compileOnlyApi`，禁止将桩打包进 APK 或作为运行时实现。
- 只为整体隐藏且不与 `android.jar` 冲突的类提供桩；公开类上的隐藏成员使用 EzHookTool 反射。
- 不放业务逻辑、Hook 注册、偏好读写或模拟系统行为。

## 签名与权限

- 新增类或成员须核对目标平台的包名、类型、参数、返回值和静态性；只声明实际需要的成员。
- 桩方法体沿用现有占位写法，不制造可能被误认为真实结果的行为。
- 编译可见不代表运行时有权限。调用方仍须处理隐藏 API、SELinux、UID 和版本差异导致的失败。
- 注释保留非显然的平台限制，不逐项解释可直接从方法签名看出的内容。

## 验证

- 静态核对签名与调用方依赖方向，确认没有与 SDK 类重复定义。
- 获准构建时检查调用模块编译和最终打包结果；不能以桩编译成功证明设备调用可用。
